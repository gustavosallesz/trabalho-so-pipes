# Jogo da Adivinhação via Pipe

Esta pasta contém os arquivos-fonte do projeto.

## Arquivos

* **chat_original.c**
  Código disponibilizado no Canvas como base para o desenvolvimento do trabalho. Implementa um exemplo de comunicação bidirecional entre processos utilizando Pipes.

* **adivinhacao.c**
  Cópia do arquivo original utilizada para o desenvolvimento da solução proposta. Neste arquivo será implementado o Jogo da Adivinhação via Pipe, conforme os requisitos do trabalho.

## Observações

* O arquivo `chat_original.c` deve ser mantido apenas como referência.
* Todo o desenvolvimento do projeto deve ser realizado em `adivinhacao.c`.
* O arquivo `chat_original.c` foi desenvolvido para ambiente Linux, utilizando chamadas de sistema como `fork()`, `pipe()`, `read()`, `write()` e `wait()`.
